# wk5-deadline-app

5주차 과제용 프로젝트입니다.

## 사용한 툴
- ChatGPT: PRD 정리, 사용자 흐름 및 가설 정리, Lo-fi 구조 기획
- Claude Code: Lo-fi 기반 working prototype 구현 및 코드 생성
- OpenAI Codex: 동일 요구사항 기반 prototype 구현 및 비교
- GitHub: 버전 기록 및 결과물 관리
- Figma: Lo-fi 와이어프레임 제작

## 효과가 있었던 핵심 프롬프트
- 5개의 Lo-fi reference를 기반으로 390×844 모바일 working prototype을 구현하도록 요청
- 목표 확인 → 외부 OTT → 이탈 앱 → 1회 개입 → 하차 후 5점 평가의 흐름을 명시
- 실제 iOS API 연동이 아닌 UX 검증용 simulation으로 제한
- Lo-fi 스타일을 유지하고 high-fidelity로 재해석하지 않도록 제한

## 실패한 시도
- 초기에 환승 감지, 마지막 재생 위치 저장, 외부 앱 진행 위치 추적 등을 서비스 기능으로 포함하려 했음
- 외부 앱의 실제 재생 위치를 읽는 기능은 PoC 범위와 구현 현실성에 맞지 않아 제외
- 이탈 앱 개입을 일반적인 SNS 전체에 적용하려 했으나, 사용자가 직접 등록한 앱에만 적용하도록 수정

## 남은 한계
- 실제 iOS에서 앱 실행을 감지하거나 차단하는 기능은 구현하지 않고 시뮬레이션함
- 실제 출퇴근 환경에서의 행동 변화는 별도 사용자 테스트가 필요함
- 소수 사용자 기반 탐색적 PoC이므로 통계적 유의성을 검증하지 않음
